# Privacy / 隐私 / プライバシー

FlowAndroid is local-first. Device serials and local file paths are displayed locally and are not transmitted to KiYouJyo servers. The initial version does not upload diagnostics, device information, firmware files or usage analytics.

The app executes locally installed official Android SDK Platform-Tools. Users must obtain firmware from trusted upstream sources. Remote update/download services are not implemented in this preview.

Before sharing logs in GitHub Issues, redact serial numbers, local paths, and other identifiable data.
